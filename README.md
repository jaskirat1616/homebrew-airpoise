# homebrew-airpoise

Homebrew tap for [**AirPoise**](https://airpoise.vercel.app/) — a macOS menu-bar app that reads your AirPods' motion sensors for posture coaching and head-gesture shortcuts. On-device, no camera, no cloud.

```bash
# Newer Homebrew asks you to trust third-party taps first (one time)
brew trust --cask jaskirat1616/airpoise/airpoise
brew install --cask jaskirat1616/airpoise/airpoise
```

Upgrade:

```bash
brew upgrade --cask jaskirat1616/airpoise/airpoise
```

### Requires

- macOS 14 Sonoma or later
- AirPods Pro / 3 / 4 / Max or Beats Fit Pro (Spatial Audio head tracking)

The build is signed (Apple Development) but not notarized — right-click the app → **Open** on first launch.

Source: https://github.com/jaskirat1616/AirPoise
